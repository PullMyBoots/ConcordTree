Runtime

ConcordTree timings for species were remeasured with K2P-gamma on L40S with 16 CPU threads and a retained engine on 8 November 2026; unchanged gene timings are reused from the previous run. DIPPER GPU was rerun on the same 900 inputs with one L40S GPU and 16 CPU threads per worker. Its runtime includes decompression where applicable, PHYLIP-to-FASTA conversion and native file-to-tree work after CUDA/TBB initialization; each input still uses a fresh CLI process. Process startup and GPU initialization are excluded, matching the exclusion of engine startup for ConcordTree. Other comparator timings retain their archived measurement conditions. Ratios describe recorded executions and are not hardware-normalized algorithmic speedups.

DIPPER timing audit

Historical DIPPER runs included fresh-process startup; the gene campaign also shared one GPU among four processes. The new measurements retain the original algorithm and options. Historical-to-new differences also reflect CPU affinity, concurrency and host state, so they do not isolate cold-start overhead. The topology figures retain historical predictions; rerun topology checks are provided separately. There is one measured run per input.
