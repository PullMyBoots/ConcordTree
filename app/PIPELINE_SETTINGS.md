# 模块流程与中间树

本地网页右下角的齿轮分别配置 Gene Tree 和 Species Tree。AP-NJ 固定为第一块，定义为纯构树，不含任何 NNI。后续兼容模块可开关、拖动或用上下箭头调整顺序，每种模块最多出现一次。

| 默认顺序 | Gene Tree | Species Tree |
| --- | --- | --- |
| 1 | AP-NJ | AP-NJ |
| 2 | Distance NNI | Distance NNI |
| 3 | MLP NNI（homogeneous 权重） | MLP NNI（heterogeneous 权重） |
| 4 | Maximum likelihood | Statistical kernel |

默认值与原生产流程一致。两类 AP-NJ 均为全位点 K2P-gamma；距离 NNI 最多4轮，停止变动比例为0（无可接受移动即停止）；MLP和后段不设用户轮数预算，停止变动比例为0.005。所有精修关闭时直接输出纯 AP-NJ 树。自定义顺序目前使用单 View。

## 参数与保存

每个精修块提供最大轮数与停止变动比例。轮数留空表示不设用户预算；已有完整状态循环、数值停滞和10000轮紧急保护仍保留。每轮接受的移动数除以内部边数 N−3，达到或低于设置比例时进入该算法的停止判定；似然方法可能还需重新拟合模型并复核。最大轮数是预算，达到预算不代表收敛。

高级参数直接传入计算实现：

- AP-NJ：投影维数、候选窗口/数量、簇代表数、landmark数、ANN邻居与扩展轮数、精确NJ收尾规模、收缩除数、种子、距离模型。
- Distance NNI：每分支代表数、最小距离改善。
- MLP NNI：每分支代表数、最小预测概率改善、批大小。
- Maximum likelihood：进化模型、最小似然改善、参数优化迭代数。进化模型仅在此处选择。
- Statistical kernel：最小目标改善、批大小；核权重和 nearest24 约定仍固定。

Reset parameters 恢复单块参数；Reset workflow 恢复当前任务的默认顺序及开关，保留已调参数；Reset all 同时恢复两类任务的默认流程、全部参数及CPU/GPU资源默认值。编辑为草稿，Save 后保存在当前浏览器；关闭或 Cancel 不保存草稿。设置只影响之后提交的任务。

`pipeline_config.py` 是前后端共享的参数范围、默认值和兼容性约定。任务独立保存 `configuration.json`，`RESULT.json.configuration` 也包含完整配置。CLI 可用 `--configuration /path/config.json`，Python API 可传入 `configuration=dict`。显式配置决定模型、轮数和停止比例；不传配置时保留旧 CLI 控制兼容性。

最终模块为似然时输出枝长；最终模块为该任务后段时可输出对应支持指标。后段之后再次运行 Distance/MLP 会改变拓扑，最终输出不携带已失效的后段枝长与支持度。中间树不附加最终支持指标。

## 暂停、恢复和取消

Pause 请求在下一个完整树边界生效：纯 AP-NJ 首次结束、距离 NNI 每轮结束、MLP每轮结束、似然/统计核每轮结束。AP-NJ 内部尚未构成完整树时无法提前下载。检查点先验证二叉树，再原子替换 `checkpoint.nwk`；`checkpoint.json` 包含阶段、轮次（适用时）、序号和taxa数量。

Paused 后显示 Download current tree，可下载当时完整 Newick。Resume 在原进程继续搜索。暂停保留内存/显存，占用本机串行计算槽位；它不是退出应用后恢复搜索的存档。总推断用时扣除暂停时间，并另记 `paused_seconds`；内部阶段计时可能包含暂停。

Cancel 终止推断进程组，在进程退出后删除任务的上传副本、结果、中间树和日志，仅保留取消状态的 `job.json`。取消排队任务立即清理。已经下载到其他位置的树不受影响。任务无运行时长限制；应用重启不自动恢复未完成推断。

## 外观

Seasons 为固定树木与山水场景，春→夏→秋→冬→春共600秒，颜色连续插值；中间卡片始终不透明，外沿保留毛玻璃过渡。左下角暂停同时冻结场景与配色。Nature 摄影主题使用原配色，不受四季循环影响。减少动态效果或节省数据时使用静态场景。

本次验证范围见 `evidence/MODULAR_SETTINGS.json`。默认树复测与自定义模块运行是执行回归，不是新准确率或性能优势结论。

Seasons 主题左下角为可拖动的小进度条，支持连续选择任意季节及其过渡位置；拖动后固定季节进度，风雨等轻微动态继续。旁边的播放按钮从当前位置继续600秒自动循环，暂停按钮冻结场景和季节进度。暂停时仍可拖动切换。选择保存在当前浏览器；Geometry 和 Nature 保持独立，不显示季节滑条。

天气与树木生命周期共同插值：晴朗春天抽叶，夏季树冠开花并伴云层、斜雨、远处缓慢闪电及湖面雨纹，秋季多云、结果、落叶和风，冬季树叶完全落尽、枝头与岸边积雪并持续飘雪。地形与树木位置固定，云量、降水、叶量、花果及配色随同一个季节相位过渡。

## 计算资源和运行面板

设置顶部提供全局 CPU threads 和物理 GPU 索引，资源设置独立于科学流程，存入当前浏览器，提交后固定于 job.json.resources。线程支持1至 min(64,本机可用逻辑核数)，个别原生算子仍有更小的内部并行上限。Web启动命令读取任务自己的资源快照，不再固定 GPU0/16线程，也不固定NUMA节点。已有任务不受后续设置影响。

Logs 设置入口已移除。右侧顶部直接显示阶段条，去掉 Running log、Saved 等标题；当前运行阶段高亮，默认四格，数量与顺序跟随任务配置。

表格按阶段分别显示：AP-NJ只有累计秒数，NNI阶段显示轮次、累计秒数、对应准则的评分／改善量和移动边数；模型拟合未进入NNI前也只显示时间。不重复显示阶段名，不给AP-NJ添加空的Round/Score列。点击阶段格子可回看，当前运行阶段仍保持高亮，进入下一阶段自动切换。指标名称分别为 Distance gain、Probability gain、Log likelihood、Score gain，各阶段含义见 web/README.md 及单元格悬停说明。结构化进度文件为 events.jsonl，仍保留 execution.log 作为原生诊断。

GPU采用常驻 nvidia-smi -l 2 持续监控，独立于推断和CPU采样；页面每2秒读取缓存。短暂中断保留显卡列表和最后读数、明确标记过期，并自动重连。
