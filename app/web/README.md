# ConcordTree 本地软件界面

本发行版供用户下载到自己的 Linux / WSL + NVIDIA 电脑上运行。启动后通过本机浏览器打开 127.0.0.1；输入、计算、结果、日志及负载监控都在同一台电脑上，不依赖中心推断服务。当前设计面向桌面浏览器。


极简双页界面，仅提供基因树和序列到物种树两种任务。
全英文提交页包含 Gene Tree / Species Tree、必要选项和 Upload，无额外标题或常驻预览提示。
选择或拖入合法文件后自动上传并提交，无 Infer 按钮。服务端确认接收后才显示 Queued。
上传卡片和结果页底部保留同一个默认收起的 Host load。收起时显示 CPU、内存和当前推断 GPU 利用率；
点击或用键盘展开，查看 CPU 利用率、已用/总内存，以及每张 NVIDIA GPU 的利用率与已用/总显存。
每 5 秒刷新，隐藏标签页暂停请求；后台每 3 秒采样并缓存，不在网页请求中同步启动 CUDA。
CPU 与内存读取 Linux /proc，GPU 通过有时限的 nvidia-smi 查询；未知读数显示不可用，不伪装成零负载。
这是运行 ConcordTree 的 Linux/WSL 主机读数。容器中的 CPU/内存是其可见的 /proc 口径，GPU 是可见设备。
`GET /api/host` 返回资源快照；`GET /api/queue` 仍供内部串行调度和提交前检查，不再显示排队格子。
提交前检查服务器状态，暂停、离线或队列满时不上传。上传中锁定控件以避免重复提交；
上传响应丢失时显示未能确认，不自动重传，以免重复排队。
零文件拖放与多文件拖放分别提示；默认仅接受真实浏览器文件，临时调试模式额外接受 VS Code 服务器文件路径。
Upload 下方的 Try example 可直接加载内置小型样例并按当前参数提交，无需准备本地文件。
当前主机另有推断时等待串行执行；不估计未经测量的等待时间。
齿轮设置分别编辑基因树、物种树的模块流程；主页面保留分支支持度开关。进化模型位于 Maximum likelihood 的高级设置。
结果页显示任务状态、实际推断阶段、可滚动、缩放和拖动的在线树预览、
Newick 下载、返回提交页。Back 返回新的 Upload，保留任务类型。
结果地址使用 `#job=<id>`，刷新后读取已有任务。超过 400 个物种的树保留完整下载，
在线预览显示数量限制提示。无任务记录、示例树、基因树合并或前端构建依赖。

默认 Geometry 保留原来的曲线生命树生长、分叉与动植物图标，每轮约23秒。
独立的 Seasons 主题固定同一处树木、山水和湖面场景，晴春抽叶、雷雨夏花、秋果与风吹落叶、冬季裸枝飘雪在600秒内渐变轮回。
背景与中央卡片同步换色；卡片内部不透明，毛玻璃仅在外部边缘过渡。
左下角可暂停背景或切换摄影主题；减少动态效果时保留静态场景。
Nature 主题每次进入随机选一张本地摄影壁纸，不自动轮播，只加载选中的照片。
左下角换图按钮手动选择下一张，避免立即重复；减少动态效果时仍可换图。
图库 `backgrounds.json` 包含 12 张特写：变色龙、虎、蜂鸟、恐龙复原、菊石、
蕨叶、茅膏菜、蘑菇、古植物标本、硅藻、植物细胞和病毒显微图像。
森林和珊瑚景观已退出随机图库。大多数下载原图长边为 4096 像素；
古植物标本为 3000 × 2252，病毒电镜为 2097 × 2097，并非所有素材均为原生 4K。
桌面表单始终居中，不随换图移动；摄影资源沿用本地 WebP，
不对主体做 AI 放大或生成。每次只请求所选设备对应的图片版本。
右下角提供小型署名和授权链接，完整来源及媒体类型见 `/credits.html`；
恐龙复原和显微图像均明确标注，古植物馆藏项目的模型分类也保留说明。
主题选择保存在浏览器本地；遵循系统减少动态效果设置，隐藏标签页暂停绘制。
摄影来源及授权见 `assets/CREDITS.md`，素材尺寸与校验值见 `assets/SOURCES.json`。
摄影素材仍可在用户生成新壁纸后替换，不含外部字体或脚本依赖。

## 运行

当前规范运行副本为 `release/V1.0.2/web/`。从本版目录使用本地环境启动：

```bash
cd /home/student_su/publish_code/research-workbench/subprojects-single/scalable-neural-phylogeny/release/V1.0.2
bash scripts/start_web.sh --port 8765
# 打开 http://127.0.0.1:8765
```

网页依赖已经独立放入本版 `.venv-web/`；科学依赖在 `.conda/env/`，无需其他发布或实验目录。清理与系统依赖边界见 [LOCAL_RUNTIME.md](../LOCAL_RUNTIME.md)。

默认接收真实任务；`--preview` 只显示网页并暂停接单。
接口通过本版 `scripts/run_local.sh` 调用 `run.py`，使用本版 `.conda/env/bin/python`；单 worker、GPU0、CPU16、NUMA0。
输入、输出和执行日志位于本版 `runs/web/<job-id>/`，已有任务已迁入；可用 `--runs` 指定项目内其他非 data 输出目录。
科学缓存与网页上传临时文件均在本版 `.runtime/cache/`。
上传文件、服务器文件和补齐后的矩阵均不设应用层大小上限；最多 16 个运行或排队任务，
任务不设运行时长上限，运行至完成或用户主动取消。上传解析在线程中执行，避免阻塞队列查询。
实际任务失败会展示失败，不返回伪造结果。
服务退出会停止其计算子进程；重启不自动重跑未完成任务。枝长和物种树的科学边界沿用发布版文档。

## 输入与选项

- **Gene Tree**：单个 PHYLIP 对齐矩阵，至少 4 个 taxa；拒绝多 locus 输入。
  模型默认为 `GTR+FO+I+G4`，另可选择 `GTR+I+G4`、`GTR+G4`、`HKY+G4`、
  `GTR`、`SYM`、`TN93`、`HKY`、`K80`、`F81`、`JC`。
- **Species Tree**：一个 PHYLIP/PAML 文本文件，每个 locus 使用独立的
  `序列数 位点数` 头和对应 MSA；总计至少 24 个 taxa。
  一个块自动用 `msa_only`；两个及以上块自动生成边界并用 `observed_loci`。
  不从已拼接的单矩阵猜测隐藏的基因边界，不提供手动分区选项。
- **Branch support**：两类任务默认勾选；取消会向后端传入 `--no-support`。
  勾选时网页在内枝旁显示数值，下载的 Newick 也保留支持度。
  基因树为 Local likelihood weight，物种树为 Quartet margin index；
  页面显示的 0–100 是支持度指标，不是经过校准的分支正确概率。

接受 relaxed sequential（包括序列换行和 PAML 的名称独占一行）及 interleaved PHYLIP；
序列名称与序列之间须有空白，不支持无分隔符的传统固定十字符名称行。
接受 UTF-8/BOM、空行、DNA IUPAC 字符及 `N ? - .`；不接受 FASTA、蛋白质或未对齐序列。
每个 locus 内名称必须唯一，不同 locus 通过相同名称对应物种；缺失物种在该 locus 补 `?`。
每个物种在全部输入中至少须有一个 A/C/G/T。文件扩展名仅用于文件选择器提示，服务端按内容验证。

多 locus 形式示意（此处仅为格式演示，实际物种树至少需要 24 个 taxa）：

```text
2 8
species_a ACGTACGT
species_b ACGTTCGT

2 6
species_a AAGGCC
species_b AAGGCT
```

## 按需预览与推断进度

完成页默认收起树预览和支持度说明。taxa ≤400 时显示 Preview，点击后才绘图；
taxa >400 时隐藏预览按钮和画布，保留完整树下载与推断用时。
推断期间左侧是一棵 SVG 生长树：种子、根、树干、分叉与叶片随后端已观察阶段从 0% 生长，只有任务成功才达到 100%。
该百分比表示阶段进度，不是时间比例，也不预测剩余时长。动画树是装饰性进度图，不是推断中的科学拓扑。
右侧顶部直接显示算法阶段条，不再显示 Running log、Saved 等标题和状态字。按本次任务已启用算法的顺序排列，默认四格；当前阶段高亮，完成阶段弱化保留，未开始阶段置暗。支持度和文件保存不额外增加格子。
下方只显示所选阶段自己的表格，随运行自动切换。AP-NJ 只显示累计秒数，不显示不存在的轮次、评分或移动边数；NNI阶段显示轮次、累计秒数、该准则的评分／改善量、移动边数。模型拟合尚未进入NNI时也只显示时间。点击已经开始的阶段格子可回看对应记录，实际运行阶段仍保持高亮；进入新阶段时自动切换过去。
各阶段指标单独命名：Distance gain 为当轮最大候选距离改善量；Probability gain 为MLP已移动边的平均概率改善量；Log likelihood 为全树对数似然；Score gain 为统计核当轮累计目标改善量。含义可悬停查看，不跨阶段比较。Time 是自本次推断开始的累计秒数，包含暂停时间。数值列定宽、不换行，极大／极小值用科学计数法；不显示 view、size、位点数或原生调试输出。
结构化事件写入本次输出的 events.jsonl；界面最多读取最新300条事件，刷新可恢复，向上滚动时保留阅读位置。execution.log 保留完整原生诊断，旧任务没有事件文件时从历史日志提取可用字段；Cancel 按既有约定删除本次日志。
桌面界面保持左侧生长树、右侧日志；系统减少动态效果时直接呈现当前生长状态并关闭摇摆。

## 模块设置和中间树

齿轮 → Run parameters 中，AP-NJ 固定为首块；其余兼容精修块可拖动或用上下箭头排序、开关。
每块提供最大轮数、停止变动比例与高级参数；最大轮数留空表示不设用户轮数预算，既有数值／循环保护仍生效。
进化模型只在基因树 Maximum likelihood → Advanced parameters 中编辑。
可恢复单模块参数、默认流程或全部默认参数。保存至当前浏览器；每次提交会在任务目录保存独立 configuration.json，运行中的配置不被后续编辑改变。

Pause 在下一个完整树边界生效：纯 AP-NJ 首次出树（距离 NNI 之前），以及之后各精修轮次完成时。
在 AP-NJ 尚未完成时请求暂停，需要等它先构建完整树。Paused 后出现 Download current tree，下载未标注支持度的当前 Newick；Resume 继续原任务。
这是保留当前进程的暂停，不是退出程序后恢复搜索的持久化存档。暂停期间保留 CPU/GPU 状态，并阻塞本机后续队列任务。
Cancel 会终止并删除本次保存文件；已有下载副本不受影响。配置和接口约定见 [PIPELINE_SETTINGS.md](../PIPELINE_SETTINGS.md)。

Seasons 主题左下角为可拖动的小进度条，支持连续选择任意季节及其过渡位置；拖动后固定季节进度，风雨等轻微动态继续。旁边的播放按钮从当前位置继续600秒自动循环，暂停按钮冻结场景和季节进度。暂停时仍可拖动切换。选择保存在当前浏览器；Geometry 和 Nature 保持独立，不显示季节滑条。

天气与树木生命周期共同插值：晴朗春天抽叶，夏季树冠开花并伴云层、斜雨、远处缓慢闪电及湖面雨纹，秋季多云、结果、落叶和风，冬季树叶完全落尽、枝头与岸边积雪并持续飘雪。地形与树木位置固定，云量、降水、叶量、花果及配色随同一个季节相位过渡。

## CPU / GPU 与持续监控

Settings 顶部设置 CPU threads 与物理 GPU 索引，所有算法共用，保存于当前浏览器。每个新任务将资源选择固定保存到 job.json.resources，启动时传入 --cpu-threads 和 --gpu；运行中修改设置只影响下次任务。线程上限为本机可用逻辑核数与64的较小值，部分原生算子有更小的内部并行上限。Reset all 也恢复资源默认值。

主机监控使用一个常驻 nvidia-smi -l 2 子进程持续读取 GPU，HTTP只访问缓存，页面每2秒刷新。CPU/RAM独立采样，不等待驱动。连续6秒没有读数会标记过期，15秒无输出或进程退出会自动重启；断连时保留最近有效显卡身份与读数并明确标注重试，不把旧值冒充实时值。首次从未成功识别时才显示监测不可用。WSL/驱动不支持完整计数器时退到显卡身份查询，缺失指标显示破折号。
